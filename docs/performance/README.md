# Aircraft performance KPIs

The RB-01 page `#/addons/performance` shows how the aircraft performs against its own
trained reference, as percentages: CRUISE, ATTITUDE, CLIMB, ENGINE, FUEL, DENSITY, ICING
and OVERALL. 100 % is the aircraft as trained.
